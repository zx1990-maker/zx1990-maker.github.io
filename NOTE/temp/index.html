    全A股 → 中证500/300 反事实预测实验报告（v2：含误差评估）

    一、实验目的

    使用全A股非SOE（民营企业）作为训练集，预测中证500/300 SOE的反事实EBI/A， 计算 predicted − actual 的 subsidy gap。

    核心问题：如果SOE是民营企业应有的EBI/A是多少？Gap是否大于模型自身的预测误差？

    训练集：全A股非SOE（民营企业），2014-2024年panel，27,722 obs，3,471 firms
预测集：中证300 SOE（117 firms，2024→2025）
        + 中证500 SOE（178 firms，2024→2025）
        + 全A股SOE 2025（1,406 firms）
        + 全A股SOE 全年度（14,821 obs，1,409 firms）

特征（t期）：FirmSize, AssetTurnover, FinancialLeverage, FixedAssetsRatio,
  CurrentRatio, CapexRatio, WorkingCapitalRatio, MarketShare, HHI
  + 二级行业固定效应

目标：EBI/A = (归母净利润_t+1 + 利息支出_t+1) / 资产总计_t+1
模型：Ridge(alpha=10), RandomForest(300 trees, depth=8), GBM(depth=4, lr=0.05)
CV：GroupKFold by firm_id, 5 folds → OOF prediction
Winsor：5%-95% clip（基于训练集分布）

信号噪声比：|Mean Gap| / CV_MAE
  < 1.0 → gap小于模型自身预测误差 → gap不显著（噪声级别）
  > 1.0 → gap大于模型自身预测误差 → gap可能有统计意义

    三、数据处理

    3.1 数据来源

    数据 文件 覆盖
    全A股 0803/A_2014_origin.xlsx ~ A_2024_origin.xlsx 11年，5,535 firms
    中证500 0803/csi500_2024.xlsx 2024→2025，499 firms
    沪深300成分股 three_benchmark_model_package/data_input/20XX/csi_features_20XX.csv 2018-2024，300 codes

    3.2 处理步骤

    1. XML解析：xlsx文件因openpyxl样式损坏，从zip提取XML手工解析
    2. 列映射：通过Wind表头[报告期] YYYY标签自动识别年份
    3. 所有制回填：2014年所有制为空（4,385行），通过后续年份stock_code匹配回填
    4. 金融过滤：剔除银行、保险、证券、多元金融、非银金融（1,309行）
    5. CSI300成分股识别：从原项目提取300个CSI300成分股代码，交叉匹配全A股
    6. EBI/A清理：剔除NaN和(-1, +1)范围外的极端值

    3.3 数据概览

    训练集（全A股民营） 27,722 3,471 +5.64% +5.55%
    CSI300 SOE 117 117 +5.16% +3.77%

    关键观察：民营企业平均EBI/A（5.64%）显著高于SOE（1.50%~5.16%）， 这是反事实预测的baseline差异。但模型的任务正是控制这些特征差异后的条件估计。

    4.2 信号噪声比解读 ⭐

    所有12个模型×目标组合的 |Gap|/MAE 均 < 1.0。

    指标 值 含义
    模型OOF预测误差（CV_MAE） 3.53~3.83pp 模型对民营企业EBI/A的典型预测误差
    所有gap的范围 −1.03pp ~ +2.82pp 全部小于CV_MAE
    Gap /MAE 范围
    最高比值 Ridge→CSI500：0.74 即使最极端的组合，gap仍小于误差

    结论：在A股同市场框架下，SOE与民营企业的EBI/A gap在所有模型和指数上 均不超过模型的自身预测误差。gap的量级（0~3pp）相对于模型的基准预测能力 （~3.5pp MAE）而言完全在噪声范围内。

    4.3 核心发现

    1. 所有gap均小于模型误差 ⭐ 最重要的发现
    2. CV_MAE = 3.53~3.83pp（模型预测民营企业EBI/A的典型误差）
    3. 所有mean gap（−1.03pp ~ +2.82pp）均 < CV_MAE
    4. |Gap|/MAE = 0.12~0.74，全部远小于1.0

    5. gap完全不显著——它们比模型自身一个标准差的预测误差还小

    6. CSI300 SOE的RF gap = −1.03pp（|Gap|/MAE = 0.28）

    7. Gap为负值：CSI300大市值SOE的实际EBI/A低于反事实预测

    8. 仅48.3%的企业gap为正

    9. CSI500 SOE的RF gap = +0.72pp（|Gap|/MAE = 0.20）

    10. 统计和经济上均接近零

    11. Ridge系统性高估gap但差距最显著（|Gap|/MAE=0.74 for CSI500）

    12. 即便如此仍 < 1.0（不显著）
    13. 线性模型的高gap是其模型偏误，不是真实的SOE效应

    七、方法论优势与局限

    优势

    1. 训练集极大：27,722个firm-year观测，3,471家民营企业
    2. 同市场预测：消除跨市场不可运输性问题
    3. 误差量化：通过OOF CV直接量化模型预测误差，为gap显著性判断提供基准
    4. 三模型对比：Ridge/GBM/RF三种模型给出方向一致、量级接近的估计

    局限

    1. CSI300成分股：从2018-2024年CSI features文件提取300 codes，可能遗漏个别调整
    2. 2014年所有制：回填的4,385行可能存在少量偏差
    3. 行业分类：所有年份使用2024年Wind行业标准

    八、结论

    在全A股非SOE（3,471家民营企业，27,722 obs）同市场反事实预测框架下：

    1. 所有gap均小于模型自身预测误差 ⭐
    2. CV_MAE = 3.53~3.83pp（模型预测民营企业EBI/A的典型误差）
    3. 所有mean gap（−1.03pp ~ +2.82pp）均小于此误差
    4. |Gap|/MAE = 0.12~0.74，全部远小于1.0

    5. gap的量级在噪声范围内，不具有统计或经济显著性

    6. 三模型（Ridge/RF/GBM）一致结论：

    7. CSI500 SOE：gap微正（+0.72~+2.82pp），|Gap|/MAE = 0.20~0.74
    8. CSI300 SOE：gap为负或零（−1.03pp ~ −0.68pp），|Gap|/MAE = 0.12~0.28

    9. Ridge系统性高估gap，但即使其极端值仍 < CV_MAE

    10. 行业层面：重资产行业（钢铁、机械）三模型一致正gap； 消费/化工行业三模型一致负gap——存在行业异质性但整体不显著

    11. 跨实验综合判断：

    12. Pooled Ridge +2.33pp → H→CSI500 RF +0.19pp → A→CSI300 RF −1.03pp
    13. 所有gap的 |Gap|/MAE 均 < 1.0
    14. 没有任何稳健证据支持SOE存在系统性的政府金融支持
    15. SOE与民营企业的EBI/A差异，在控制了企业特征和行业后，完全在模型噪声范围内
